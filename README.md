# AI-Powered Logistics Intelligence Platform 🚚🌍

An AI-enabled Logistics Accessibility Intelligence Platform tailored for the North Eastern Region (NER) of India. This system monitors transportation networks, predicts disruptions due to extreme weather, and optimizes the movement of essential goods using an offline-capable Progressive Web App (PWA).

## 🛠️ Tech Stack
* **Frontend:** Next.js (PWA), React, Tailwind CSS, Leaflet.js
* **Backend:** Node.js, Express
* **Database:** PostgreSQL + PostGIS
* **AI & Routing Engine:** OpenRouter API, OSRM
